NAVIGATION NOTES

H Hugo   N Nebula   L Locus SF / early Novel   C Arthur C. Clarke   B BSFA. Each book shows its original Goodreads average, star-rating count, adjusted rating, and a weighted score. SEQUEL means an earlier novel is recommended first; those books receive an 8-point ranking penalty and are excluded from default suggestions. A shared universe alone is not treated as a sequel.

THE MATH: adjusted Goodreads = (ratings count × average + 20,000 × 3.90) / (ratings count + 20,000). Score = 12 × adjusted Goodreads + 40 × (award points / 44) − 8 for sequels. Award points: Hugo 10, Nebula 10, Clarke 9, Locus 8, BSFA 7. Award-count groups stay separate, then books are sorted by score. Evidence weight = rating count / (rating count + 20,000); this is a shrinkage factor, not a probability of correctness.

ARCHIVE STATUS: Checkmarks save in this browser on this device. They do not modify GitHub automatically or sync across devices. Use to send your progress in chat for a permanent repository update.
